# Galaxy-Classification-CNN
A lightweight (7MB) CNN trained  to classify galaxies from the GalaxyMNIST database, achieving a validation accuracy of around 87%. This project was created together with two colleagues (R. Di Lauro & T. Formisano) in the context of the Computational Intelligence course during the B.Sc. of Physics at the University of Naples. The data used for the training: the [GalaxyMNIST dataset](https://github.com/mwalmsley/galaxy_mnist) where labels are taken from [Galaxy Zoo DECaLS](https://ui.adsabs.harvard.edu/abs/2022MNRAS.509.3966W/abstract).

This repository contains:
- The pre-trained model in its best iteration.
- A Jupyter notebook (in Italian) providing useful notions about Machine Learning (ML), Neural Networks (NN), Convolutional Neural Networks (CNN), as well as the data augmentation procedure, the construction of the CNN, the training and validation of the model itself. Lastly, criticalities of the model are briefly discussed.

Unluckily the dataset it too large to be included in the repository, but I'll gladly send it to anyone who asks.
