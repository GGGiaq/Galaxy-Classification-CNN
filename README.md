# Galaxy-Classification-CNN
A lightweight (7MB) CNN trained  to classify galaxies from the GalaxyMNIST database, achieving a validation accuracy of around 87%. This project was created together with two colleagues (**R. Di Lauro & T. Formisano**) in the context of the _Computational Intelligence_ course during the B.Sc. of Physics at the _University of Naples_. The data used for the training: the [GalaxyMNIST dataset](https://github.com/mwalmsley/galaxy_mnist) where labels are taken from [Galaxy Zoo DECaLS](https://ui.adsabs.harvard.edu/abs/2022MNRAS.509.3966W/abstract).

This repository contains the **pre-trained model** in its best iteration, as well as a **comprehensive Jupyter notebook** (in Italian) providing useful notions about Machine Learning (ML), Neural Networks (NN), Convolutional Neural Networks (CNN). The notebook also includes the **augmentation procedure**, the **construction** of the CNN, the **training and validation** of the model itself and finally also a measure of the goodness of the CNN throuhg the **confusion matrix**. Lastly, criticalities of the model are briefly discussed.

Unluckily the dataset it too large to be included in the repository, but I'll gladly send it to anyone who asks.
